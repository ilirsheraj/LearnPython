# LearnPython

This is the code of the amazing book by Fabrizio Romano and Heinrich Kruger. Im going through it and writing the code along, and despite some of the stuff being too basic, I discovered that I'm enjoying coding, even in the age of AI :)

Besides that, I am planning to use many of these chapters for an introductory Python course for a bunch of students. The book is very well written, fun to read through and the examples are simple and generalistic, not heavy computation based like a typical MIT introductory course on Python.
